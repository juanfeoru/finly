# Finly

Personal finance dashboard built with React and TypeScript to manage income, expenses, budgets, and financial activity.

## Features

- Dashboard with financial summary
- Transaction management

  - Add transactions
  - Edit transactions
  - Delete transactions
  - Search transactions
  - Filter by type and category
  - Pagination

- Budget management

  - Create budgets
  - Edit budgets
  - Delete budgets
  - Monthly budget tracking
  - Spending progress

- Financial analytics

  - Income vs. expenses
  - Income and expense evolution over time
  - Expenses by category
  - Period filtering

- CSV export for transactions
- Data persistence with Local Storage
- Responsive design for desktop, tablet, and mobile
- Empty states for sections without data

## Tech Stack

- React
- TypeScript
- React Router
- Tailwind CSS
- Recharts
- Lucide React
- Vite

````

## Getting Started

Clone the repository:

```bash
git clone https://github.com/juanfeoru/finly.git
cd finly
````

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run
```
